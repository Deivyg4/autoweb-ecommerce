# AutoWeb - Plantilla Básica de Tienda de Repuestos Automotrices

**AutoWeb** es una **plantilla de ejemplo básica** para una tienda en línea de repuestos automotrices, desarrollada únicamente con HTML, CSS y JavaScript puro. Está pensada como punto de partida para proyectos de e-commerce sencillos, demostraciones, prácticas o aprendizaje.

---

## 🚗 Características Principales

- **Catálogo de productos** con filtros básicos.
- **Carrito de compras** (funcionalidad frontend, sin backend).
- **Sección de ofertas** y productos destacados.
- **Formulario de contacto** con validación simple.
- **Animaciones y diseño responsive** para móviles y escritorio.
- **Iconos de redes sociales** usando [Boxicons](https://boxicons.com/).
- **Newsletter** para suscripción de usuarios.
- **Secciones informativas**: Nosotros, Beneficios, Preguntas Frecuentes, etc.

## 🎯 Funcionalidades Incluidas

- Navegación entre páginas estáticas.
- Carrito de compras (solo en frontend, usando localStorage).
- Visualización y filtrado básico de productos.
- Sección de ofertas y promociones.
- Formulario de contacto funcional (sin envío real).
- Diseño adaptable a dispositivos móviles.

## 💻 Páginas Incluidas
1. **Inicio**: Landing page con productos destacados
2. **Productos**: Catálogo de productos
3. **Ofertas**: Sección de promociones
4. **Nosotros**: Página informativa
5. **Contacto**: Formulario de contacto

## 🎨 Características de Diseño
- Diseño responsive
- Interfaz limpia y moderna
- Estructura HTML semántica
- Estilos CSS organizados
- Animaciones básicas

## ⚠️ Limitaciones

- **No incluye backend** (no hay base de datos ni servidor).
- **No tiene autenticación** de usuarios.
- **No incluye pasarela de pagos**.
- **El carrito solo funciona en el navegador** (no se guarda en servidor).
- **No es un sistema listo para producción**.

## 🚀 Cómo Usar

1. Descarga o clona este repositorio.
2. Abre `index.html` en tu navegador.
3. Personaliza el contenido, imágenes y estilos según tus necesidades.
4. Si deseas agregar backend, deberás implementarlo por tu cuenta.

## 📝 Personalización

- Cambia los colores en `css/styles.css`.
- Actualiza las imágenes en la carpeta `img/`.
- Modifica los productos en los archivos HTML o en el JS correspondiente.
- Ajusta los textos y secciones según tu negocio o proyecto.
